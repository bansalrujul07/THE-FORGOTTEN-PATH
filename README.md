# 🌌 The Forgotten Path

*A 3-Level Memory-Based Maze Adventure*

> The maze fades after seconds. Remember the path, navigate the darkness, and escape before time runs out.

## 🎮 About the Game

**The Forgotten Path** is a 2D maze adventure where memory is your greatest tool.

At the beginning of each level, the maze is revealed for a few seconds. Once the walls disappear, you must rely on your memory to navigate through the darkness, avoid hidden walls, and find the exit before the timer reaches zero.

But you aren't completely alone in the dark. Use your limited **Echo Pulse** ability to briefly reveal nearby maze walls and help you find your way.

Can you remember the path and escape all three levels?

## ✨ Features

- **Memory-Based Gameplay:** Study the maze before it disappears and navigate using your memory.
- **Disappearing Maze:** Walls fade away but remain physically solid, making navigation challenging.
- **Echo Pulse Ability:** Reveal nearby maze walls for a short time using limited charges.
- **Three Progressive Levels:** Complete increasingly challenging stages:
  1. The Awakening
  2. The Lost Passage
  3. The Forgotten Depths
- **Countdown Timer:** Reach the exit before time runs out.
- **Increasing Difficulty:** Each level introduces tighter time limits and fewer Echo Pulse charges.
- **Win and Game Over States:** Complete levels, progress to the next stage, or retry your journey.

## 🕹️ Controls

| Key | Action |
|---|---|
| ↑ / W | Move Up |
| ↓ / S | Move Down |
| ← / A | Move Left |
| → / D | Move Right |
| E | Activate Echo Pulse |

*Use the arrow keys to move. WASD movement depends on your input map configuration.*

## 🧩 How to Play

1. Start a level and observe the maze during the preview.
2. Memorize the walls, pathways, and exit location.
3. Wait for the maze to disappear.
4. Navigate through the invisible walls using your memory.
5. Activate Echo Pulse when you need help.
6. Reach the exit before the countdown ends.
7. Complete all three levels to finish the game!

## 🚀 Getting Started

### Prerequisites

- Godot Engine 4.x (Standard version)
- Git (optional, for cloning the repository)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/bansalrujul07/THE-FORGOTTEN-PATH.git
   ```

2. Open Godot Engine.

3. Select **Import** and navigate to the cloned project folder.

4. Open `project.godot`.

5. Run the project using the Play button.

## 🎯 Project Objective

The goal of this project is to create an engaging game that challenges spatial awareness, memory, and decision-making under time pressure.

It explores how simple mechanics, such as disappearing visuals and limited-use abilities, can create an exciting gameplay experience.
